哲学

机から少し浮いた質感を 2 段重ねの drop shadow で表現。色は rgba(168,117,96) / rgba(201,141,128) / rgba(184,148,85) / rgba(61,46,42) の warm 系のみ。

注: Glass stage は backdrop-filter: blur(16px) で表現する 別レイヤー。shadow とは混同しない — Glass = 透明度＋ぼかし、Shadow = 浮き感。

禁止 (Matte 哲学準拠)

  • ✕ shadow-glow-* — ハロー浮きすぎ
  • ✕ shadow-elevated-light — 浮きすぎ
  • ✕ inset highlight — Matte 哲学に反する (旧 luxe の inset 0 1px 0 rgba(255,255,255,.6) は削除済み)
  • ✕ 釉薬グラデ — Matte 哲学に反する (bg は solid のみ、影で階層を出す)
